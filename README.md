# English

# Daily Water Intake Calculator

This project is a simple C# console application that calculates the ideal amount of water a user should drink daily based on their weight.

# Features

- Takes the user's weight in kilograms.
- Calculates daily water needs in liters based on scientifically accepted approximate ratios.
- Prints the result on the screen in an easy-to-understand format.,




# Deutsch

# Täglicher Wasseraufnahme-Rechner

Dieses Projekt ist eine einfache C#-Konsolenanwendung, die die ideale Menge Wasser berechnet, die ein Benutzer täglich basierend auf seinem Gewicht trinken sollte.

# Funktionen

- Nimmt das Gewicht des Benutzers in Kilogramm auf.
- Berechnet den täglichen Wasserbedarf in Litern basierend auf wissenschaftlich akzeptierten ungefähren Verhältnissen.
- Gibt das Ergebnis auf dem Bildschirm in einem leicht verständlichen Format aus.



# Türkçe


# Günlük Su Tüketimi Hesaplayıcı

Bu proje, kullanıcının kilosuna bağlı olarak günlük ideal su miktarını hesaplayan basit bir C# konsol uygulamasıdır.

# Özellikler

- Kullanıcının kilosunu kilogram cinsinden alır.
- Bilimsel olarak kabul edilen yaklaşık oranlara göre günlük su ihtiyacını litre cinsinden hesaplar.
- Sonucu ekranda anlaşılması kolay bir formatta gösterir.
